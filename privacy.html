Privacy policy

Last updated: 18 October 2026

Home Assistant is a personal, single-user application. Its only user is its owner, who also runs it.

What data it uses

With the owner's permission it accesses the owner's own Google account data (calendar events, tasks and, if enabled, email) through Google's APIs. It uses this only to show, print and manage the owner's own schedule, tasks and messages.

Where data goes

  • Data is processed and stored only on the owner's private home server.
  • Data is not sold, shared with third parties, or used for advertising.
  • Data is not used to train general-purpose AI models.

Google API Services

Home Assistant's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
